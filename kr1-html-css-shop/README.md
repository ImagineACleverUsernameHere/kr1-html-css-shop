# StyleMuse — персональный помощник по стилю

## Описание
StyleMuse — учебный многостраничный frontend-проект каталога одежды, украшений и косметики. Идея проекта — показать, как можно персонализировать подборки товаров на основе предпочтений пользователя.

Текущая версия является демонстрационным прототипом. Подбор стиля выполняется по ответам на короткий опрос, а товары, цены и контактные данные условные. Регистрация, анализ фотографий, серверное хранение данных и оплата не реализованы.

## Страницы проекта
- `index.html` — главная страница и демонстрационный опрос для подбора направления стиля.
- `catalog.html` — каталог с фильтрами, избранным и сравнением двух товаров.
- `product.html` — подробная страница демонстрационного образа, таблица характеристик и модальная форма.
- `order.html` — форма заявки с базовой валидацией.
- `contacts.html` — контактная информация и форма обратной связи.

## Используемые технологии
- HTML5: семантическая разметка, несколько страниц, формы и таблица;
- CSS3: переменные, Flexbox, Grid, состояния `:hover` и `:focus-visible`, базовая адаптация, БЭМ-именование классов;
- JavaScript: демонстрационный опрос, фильтрация каталога, избранное в `localStorage`, сравнение товаров, модальное окно и проверка форм;
- Git и GitHub: хранение исходного кода и публикация через GitHub Pages.

## Как запустить
1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Visual Studio Code.
3. Откройте `index.html` в браузере. Для удобства можно использовать расширение Live Server.

## Как проверить функции
1. На главной странице ответьте на три вопроса и нажмите «Получить мою подборку».
2. Перейдите в каталог, попробуйте фильтры и поиск.
3. Добавьте товары в избранное, затем выберите два товара для сравнения.
4. Откройте «Образ дня» и нажмите «Запросить подбор», чтобы проверить модальное окно.
5. Откройте страницу заявки и попробуйте отправить пустую форму, а затем заполненную.
